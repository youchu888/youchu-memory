# 归因四条件测试验数对候选，不对入围

## 背景

四条件入围发布到测试海豚后补数验数。T-1 注册有量，但 `attribution_flag=1` 为 0。

## 坑 / 错误做法

- 默认补 T-1，SUCCESS 但结果被覆盖成 0，误判 SQL 没产出。
- 用入围人数对结果行数。结果 SQL 只落 `source_event_id` 非空的注册。

## 正确做法

- 先验四条件入围 > 0 再选业务日。`$[yyyy-MM-dd-1]` 的 schedule 是业务日次日 05:20。
- 期望：结果行 ⊆ 入围，且行数 = 有落地页候选的入围数。
- 影子 `_r` 读 paimon。测试 SR 的 `dwd` 有数、paimon 当日 0 行时，影子 SUCCESS 且 0 行是数据空，不是入围写错。
