# 对外回复禁用「主人」，用「你」直说；内部记忆可留出处词，输出必须剥离

## 背景

TG Cursor 共用会话轮换前自动蒸馏（session-rotate）。

## 正确做法

对外回复、代码注释、SQL、文档、commit、outgoing 一律禁用「主人」和「某某定案」（写成「确认 / 定案」）。私有 memory 可留出处；一写进仓或对外文件必须剥离。
