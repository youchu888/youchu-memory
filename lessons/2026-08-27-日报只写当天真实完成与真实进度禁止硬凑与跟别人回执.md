# 日报只写当天真实完成与真实进度；禁止硬凑、禁止跟别人回执写卡点

## 背景

2026-08-27 主人纠正：① 测试环境已就绪却仍写「继续等待」是跟知秋/狂人回执跑，不是写我们干了什么；② 「漫画发产前核对」「自动工作簿巡检」主人无印象，属硬凑。

## 坑 / 错误做法

- 为凑满 3 条，把「跑过一次斜杠命令 / 机器人自动发进展」写成「今日完成」
- 用别人「先等 test 环境」的旧回执当当日结果，覆盖主人已知的真实进度
- 写日报时大扫 transcript / 群聊 / lesson，拖很久却不先问「今天你认哪几件」

## 正确做法

1. **只写当天我们真正做完的事 + 真实进度**；没干就少写，宁可 1～2 条，禁止硬凑
2. **以主人交办与本机交付为准**；别人回执只作对照，不得单独当结果条
3. 自动巡检 / 只读探查 / 半截 stage7 指引 → **默认不进「今日结果」**，除非主人明确算交付
4. 卡点只写「当日明确要交却没交」的；环境已就绪就写就绪与下一步，不写「继续等待」
5. 写稿优先：当日 work-log 手写 bullet → 主人私聊交办 → 有证据的交付；不要为填满去翻全库

## 验证

主人看结果条能立刻对上「我今天干过」；对不上的条视为硬凑，须当场删改。
