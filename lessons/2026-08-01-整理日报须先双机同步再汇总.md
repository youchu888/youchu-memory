# 整理日报须先双机同步再汇总

## 背景

主人 2026-08-01：在新 Mac 干的活，旧 Mac 写日报经常汇不到；要求「整理今天日报」默认多 Agent / 多设备，**先同步再汇总**。

## 坑 / 错误做法

- 只读本机 transcript / 当前会话就交日报
- 假设 10 分钟 launchd 已自动把新机流水拉齐（新机可能未写 work-log 或未上线）
- 以为 Cursor 对话会随 memory git 跨机（**不会**）

## 正确做法

1. 触发词含「整理今天日报 / 日报 / 今日总结」→ 默认多 Agent + 双机
2. 先跑：`bash ~/.dc-platform/scripts/prepare_daily_report_sync.sh`
3. 读 `~/.dc-platform/memory/work-log/当日.md` + `hosts/new-mac|old-mac/`
4. 缺机 hosts → 回复里点明；编码机收尾必须写 `.cursor/work-log/当日.md`

## 验证

- 旧机 sync 日志有 pull/push；`hosts/new-mac/YYYY-MM-DD.md` 在新机有活时存在
- 日报正文能覆盖新机当日流水条目

## 关联
