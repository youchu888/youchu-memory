# OneHR 设备页刷新：又初↔Ethan 账号往返后再截图

## 背景

只开 `settings→devices` 往往仍是缓存列表，上下班截图几乎一样。主人确认：切到 Ethan 再切回又初可强制刷新。

## 做法

1. `onehr_tg_click_account`：Accessibility 打开 Window 菜单，点账号名（`又初` / `Ethan`）
2. 截图脚本流程：`又初→Ethan→又初` → `settings→devices` → 截图
3. 校验必须：设置侧栏 + 设备页 + **主号又初**（拒 Ethan 页 / 聊天 overlay）

## 配置

- `ONEHR_TG_PRIMARY_ACCOUNT` 默认 `又初`
- `ONEHR_TG_BOUNCE_ACCOUNT` 默认 `Ethan`
- 调试：`--skip-refresh` 跳过往返

## 注意

- 需给运行进程「辅助功能」权限（launchd 里跑 bash/python 时若失败，检查系统设置）
- 不重新登录；不强制注销其它设备

## 验证

```bash
bash ~/.dc-platform/scripts/onehr_telegram_devices_screenshot.sh
# 期望：navigate 含 bounce:Ethan→又初；OCR OK account=又初
```
