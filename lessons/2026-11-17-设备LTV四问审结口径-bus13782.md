# 设备 LTV 四问审结口径（#13778 → bus#13782）

## 背景

承接 #13778 排队审结（见 `2026-11-17-设备LTV四问-狂人排队审-结论bus回猫猫-bus13778.md`）。狂人审毕，结论 bus#13782 回蓝猫；与设备 cohort / 进队留存（#13580 / #13607）同属设备域，为新增设备 LTV 开发定案。

## 坑 / 错误做法

- 付款设备大量不在设备快照时仍继续开发 LTV，不先查归因 / 覆盖链
- 订单冲突处理把**整日**金额置空，而非仅冲突涉及设备当天为空
- 在 LTV 内重算五类 `channel_type`，或绕过快照 channel 自算渠道
- 国家、设备类型取事件侧或主档「最新」而非注册快照
- 队列起始日含 10-14，与业务约定的进队起点不一致

## 正确做法

1. **付款 vs 快照**：付费设备约 67.8% 不在设备快照属异常，须**先归因再开发**；订单冲突仅让**涉事设备当日金额为空**，禁止整日清空。
2. **渠道**：只读快照 `channel`；五类 `channel_type` **不在 LTV 重算**；需求方坚持五类 → **报知秋定案**，开发不自决。
3. **维度**：国家、`device_type` 以**设备快照**为准。
4. **队列**：进队统计自 **2025-10-15** 起，**10-14 不入队**（业务日口径）。

## 验证

- bus#13782 已回蓝猫；ETL / 对账 SQL 与上四条一致；五类 channel 无知秋书面定案前不落代码。
