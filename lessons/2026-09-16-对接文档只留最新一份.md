# 对接类文档只留最新一份，删旧日期稿与跨目录副本

## 背景

归因对接曾同时存在总册、升级说明、相对旧版变更，以及 result_d / v1011 / ads 多份副本，Changes 里堆一串带日期的 md。

## 坑 / 错误做法

- 每改一版就新建 `*-YYYY-MM-DD.md`，旧稿不删
- 同一内容在 session 包与表目录各放一份

## 正确做法

1. **一类对接只留一份最新**：就地改或新日期稿落地后 **删掉更旧日期稿**
2. **不跨目录复制**：表专文放表目录（如 `ads/.../无候选原因-后端对接.md`）；包级总述只放 session/包目录一份
3. 其它文档改链接指到最新稿，禁止留断链
4. playbook / README / SQL 等活资产照常保留（不是「带日期的对接快照」）

## 验证

`find` 同主题对接稿应 ≤1；README 链接可打开。
