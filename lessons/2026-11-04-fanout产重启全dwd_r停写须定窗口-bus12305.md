# 产 fanout 合入重启会全表 dwd_r 短暂停写，须先定窗口

## 背景

点击率 `dwd_app_pageitem_d_r` fanout 草稿经 prod 量级修正后，狂人 bus#12305 审定 **bucket=16、并行度 8** 通过；合入前需重打 jar 并重启生产 fanout。

## 坑 / 错误做法

- 未协调窗口即重启产 fanout（**所有** dwd_r 实时写会短暂中断）
- 审定通过后仍用 test 行数或旧 bucket=1 配置合入

## 正确做法

1. bucket/并行度以审定值为准（本例 16 / 8），与 DDL、manifest 三处一致
2. 合入 + 重启：**先与知秋约定执行人与维护窗口**，再动手
3. 依赖新 fanout 的 Spark/海豚正式产发，排在 fanout 合入并重启完成之后

## 分工（bus#12313 / #12312）

| 谁 | 做什么 |
|----|--------|
| 狂人 | 生产建 `paimon.dwd.dwd_app_pageitem_d_r`（DDL=`44018424`；建完 `SHOW CREATE` 核列/PK/bucket=16/first-row）；**fanout 重启前建好**，不靠首跑自动建；经知秋转斯科特合入 |
| 斯科特 | 只合入 fanout 并重启（不在 bus；由知秋转） |
| 知秋 | 定重启人与窗口 |
| 又初 | **不动**；窗口定了、狂人通知后再挂影子 |
