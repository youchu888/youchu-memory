# Yarn 日跑脚本须拦截已知 0 行源表的 app（如 app_2556），否则 exit 0 也会形成假成功

## 背景

TG Cursor 共用会话轮换前自动蒸馏（session-rotate）。

## 正确做法

Yarn 日跑脚本须拦截已知 0 行源表的 app（如 app_2556），否则 exit 0 也会形成假成功
