# 狂人 bus 有动作清单时禁止快车道「已知悉」空结案

## 背景

bus#8437 是验收回执，但正文明确要求：pending 别动、把 test 海豚 wf v271 的 `task_params` SQL 全文贴 bus、确认环境是 43.212.183.54。快车道把「pending 文件就放着别动」里的「别动」判成 `reply_only`，12 秒内自动回了「收到，已知悉」，活没干。

## 坑 / 错误做法

- 看到「验收通过 / 别动 / HOLD」就当整封只回不干
- 快车道模板 `[REPLY] bus#N 收到，已知悉。` 当结案
- 主人已说过：狂人安排的事要马上做，并沉淀经验；回「懂了/已知悉」不等于交付

## 正确做法

1. 默认 `work`。只有狂人写明「不用做 / 先待命 / 不用回」且**没有**材料清单时才 `reply_only`
2. 正文只要有「麻烦你 / 贴 bus / SQL 正文 / 要核 / 请确认 / 对吧」→ **work**，即使同时写了 HOLD / 别动
3. ACK 一行即可；reply 必须带所要材料（SQL 全文、环境名、核验结论），禁止空已知悉
4. 分类器：`message_needs_work` 先看 `_HAS_WORK_ASK`，再看 opt-out；去掉裸「别动」关键词

## 验证

```bash
python3 -c "
import sys
sys.path.insert(0, '.claude/database/scripts/notify')
from agent_bus_state import message_bus_mode
kw = dict(from_agent='worker_ant', to_agent='youchu_ai')
assert message_bus_mode('先 HOLD', **kw)=='reply_only'
assert message_bus_mode('pending 放着别动。麻烦你把 SQL 正文贴 bus 给我', **kw)=='work'
"
```
