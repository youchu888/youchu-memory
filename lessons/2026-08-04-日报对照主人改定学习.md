# 日报对照主人改定稿学习写法

## 背景

2026-08-04 又初初稿经主人改定后上传。以后写日报按改定方向收敛，减少返工。

## 对照差异（初稿 → 改定）

| 点 | 初稿问题 | 主人改法 |
|----|----------|----------|
| 过程细节 | 写「生产侧此前一次补数仍走旧版逻辑、未带上新有效会话口径」等排查旁白 | 删掉；只留「补齐材料 + 交复审」结果句 |
| 优先级/决策 | 未写发版策略变化 | 补「生产发版延后，优先度调为最低」 |
| 收口 | 三条未统一标「已完成」 | 当日交付闭环的条目加「已完成」 |
| 明日动作 | 死盯停留时长代发、截止一律「明日」 | 改跟真实下一优先任务「页面访问指标开发」，截止「周五」 |

## 正确做法

1. **结果向**：写交了什么、定了什么；少写内部核对过程（旧版补数、版本号、排查链路）
2. **决策入稿**：优先度下调 / 发版延后 / 口径归另线 —— 主人或知秋已拍的，必须写进结果条
3. **已完成**：当日该专项交付动作已做完（材料交齐、提审完成、验数跑通）就标「已完成」；别把「等别人发版」写成未完成后缀
4. **明日动作可多条**：TOP1/TOP2…；按工作量估截止（明日 / 周三 / 周五 / 下周），不要默认「明日」
5. 主人改定稿后：覆盖本地+memory → 上传云端（若要求）→ `--force` 重推 TG

## 验证

下次日报若主人少改或不改，即收敛有效。
