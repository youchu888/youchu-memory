# 日报说人话、条数灵活；禁止 TG 双推

## 背景

主人 2026-08-28：TG 收到两份日报；正文太官方，之前说过要写人话一点；不一定非要 3 条。

## 双推根因（2026-08-28）

1. **21:45 fallback** 发现稿已写好、marker 未写入 → 跑 `post_daily_report_to_dm.py` 推 TG
2. **21:30 唤醒的写稿会话** 几乎同时也在跑同一脚本（或规则要求「对话交正文」再贴一遍全文）
3. 两路在 marker 写入前各推一次 → 私聊两条几乎相同的内容

## 文风坑

1. 把「通俗但正式 + 40~70 字 + 通常 3 条」执行成公文腔 + 内部代号 + 硬凑 3 条
2. **08-28 二轮**：又把「说人话」误解成口语（「今天主要在搞」），与主人改定稿（08-04/08-06/08-17）完全反着写

主人改定稿在 memory 里（`lessons/2026-08-04-日报对照主人改定学习.md` + 多份 `reports/日报-*.md`），写前未对照。

## 正确做法

1. 写前必读 `feedback_daily_report_golden_style_from_owner_edits.md` + 最近定稿
2. 句式：`指标库：按知秋要求…；…对齐/回执，已完成；` —— **不是口语体**
3. 结果 1～3 条；弱条删；定稿后只推 TG 一次
