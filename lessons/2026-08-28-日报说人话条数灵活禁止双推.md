# 日报说人话、条数灵活；禁止 TG 双推

## 背景

主人 2026-08-28：TG 收到两份日报；正文太官方，之前说过要写人话一点；不一定非要 3 条。

## 双推根因（2026-08-28）

1. **21:45 fallback** 发现稿已写好、marker 未写入 → 跑 `post_daily_report_to_dm.py` 推 TG
2. **21:30 唤醒的写稿会话** 几乎同时也在跑同一脚本（或规则要求「对话交正文」再贴一遍全文）
3. 两路在 marker 写入前各推一次 → 私聊两条几乎相同的内容

## 文风坑

把「通俗但正式 + 40~70 字 + 通常 3 条」执行成：**公文腔 + 内部代号堆砌 + 硬凑 3 条**。主人要的是**说人话**（像口头跟主管汇报），条数灵活。

## 正确做法

1. **结果 1～3 条**，一条能说清就一条；禁为凑条数拆事
2. **说人话**：业务主语 + 做了什么 + 结果；内部词换成听得懂的说法
3. 定稿后**只推 TG 一次**；对话确认路径即可，**禁止再贴全文**
4. 写稿后**立刻** `post_daily_report_to_dm.py`，避免和 21:45 fallback 抢跑
