# SR 分区红线说过仍漏：影子 DDL 须空列表或够长历史

## 背景

`sr-create-history-partitions.mdc` / 红线 26 早已要求按日 RANGE 建表带历史分区。2026-11-07 野花拿 `dws_app_channel_dau_d_paimon_shadow` 建表 SQL，仍只有 `p20261016`/`p20261017` 两天。

## 坑 / 错误做法

- 以为 properties 里写了 `history_partition_num=30`，CREATE 里只列两天也「等于有历史」
- 从试验窗口 / SHOW CREATE 抄短分区列表进仓库，提审前不扫分区
- 产发总册只盯 mount/owned，分区未做硬勾选

## 正确做法

1. 默认：`PARTITION BY RANGE(col) ()` + `history_partition_num=30` + `start=-10000`
2. 或显式 ≥30 天 / 足够长的 `START…END…EVERY`
3. Spark 提审/S7 建表前：对 `ops_system/spark_migrate/**/*ddl*.sql` 扫 `PARTITION p20*` 个数，`<28` 且非空列表 → 阻断
4. 归类入口：`playbook_spark_prod_publish.md` §10

## 验证

`spark_migrate` OLAP DDL 审计 `BAD_THIN=0`；野花用仓库最新 DDL 建表。
