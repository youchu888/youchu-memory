# 设备 LTV：无 SDK 初始化付款剔除 + 覆盖率检查（#13785 → bus#13786）

## 背景

承接 #13778/#13782 四问审结。狂人回 #13785，bus#13786 定案：**从未做过 SDK 初始化的设备**产生的付款不进设备 LTV；口径可冻结开发。

## 坑 / 错误做法

- 把全量财务充值与设备 LTV 汇总对平，忽略大量非 SDK 路径付款
- 未做过 SDK 初始化的设备仍归入某「首次 SDK 组」
- 表说明未写明仅覆盖 SDK 设备，下游误当全渠道充值汇总

## 正确做法

1. **纳入范围**：仅 **有过 SDK 初始化** 的设备计入设备 LTV；原文无首次 SDK 组可归的付款 **排除**。
2. **表说明**：文档写明表 **只覆盖 SDK 设备**。
3. **对账预期**：样本日（如 11-15）SDK 可归类付款金额约占财务总充值 **32.2%**，**不与财务总充值对平** 为正常。
4. **运维**：任务链增加 **按日覆盖率检查**（付款/SDK 覆盖比例等）。
5. **开发状态**：本条及 #13782 四条齐备后，**口径冻结**，可继续 ETL/S4。

## 验证

- bus#13786 已回；ETL 过滤条件排除无 SDK 初始化设备；每日覆盖率检查有产出；表说明已更新。
