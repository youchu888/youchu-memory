# 海豚新任务挂到 task 列表最后面

## 背景

管理报表部门周/月、产品周挂进 `wf_ads_日报表_日` 时，落在定义列表中段（约第 24–26 项），后面还有一批老 ads 日表。约定：以后新建/挂任务一律挂到 **taskDefinitionList 末尾**。

## 坑 / 错误做法

- `create_task_in_workflow` / 手工 PUT 时插在中间或紧挨上游节点附近
- 只关心 DAG 边（pre/post），不关心定义列表顺序 → UI/导出顺序乱、后人难找

## 正确做法

1. 新 SQL task：**追加到 `taskDefinitionList` 最后**
2. DAG：按依赖连边（如挂在 `ads_channel_metrics_daily_d` 后），边与列表顺序无关
3. 发布/挂槽前用 `get_workflow` 扫一眼：新 task 应是列表最后几项之一

## 验证

`taskDefinitionList` 末尾能看到新 task 名；依赖边仍指向正确上游。

## 关联

- 例：`wf_ads_日报表_日` test；三表 `ads_dept_promotion_summary_w/m`、`ads_product_promotion_summary_w`
