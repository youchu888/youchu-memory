# OneHR 打卡禁止上传过期截图；窗口定位不走 System Events

## 背景

主人 2026-08-31：感觉打卡上传的图不是最新截图。

## 坑 / 错误做法

- launchd 里 `osascript` + System Events 读窗口会 AppleEvent 超时（-1712，约 2 分钟）
- `take_screenshot` 失败后 `latest_screenshot()` 拿目录 mtime 最新文件，**不管是哪一天**
- 08-31 / 08-29 上班卡实际上传的是 **08-28 22:32** 的 `telegram_devices_20260828_223208.png`

## 正确做法

1. 窗口定位用 CoreGraphics helper（`onehr_tg_window_info.swift`），deeplink `tg://settings/devices` 打开设备页
2. 只上传 **180 秒内** 新截的 PNG；失败就失败并通知，禁止回退旧图
3. 截图脚本失败重试 3 次（第 2 次起 `--capture-only`）
4. 日志必须写 `将上传截图 path age=Ns`

## 验证

```bash
ls -lt ~/Desktop/CH/telegram/telegram_devices_*.png | head
bash ~/.dc-platform/scripts/onehr_telegram_devices_screenshot.sh
# 期望：当天新文件，且图为「登录设备管理」
rg "截图失败，尝试使用目录最新图|将上传截图" ~/.dc-platform/onehr/logs/checkin_$(date +%Y%m%d).log
```
