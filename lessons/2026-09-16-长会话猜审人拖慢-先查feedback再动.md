# 做事整体偏慢：先结论、禁重探、一题一会话

## 背景

主人连纠：不是某一题，是搞事情整体都慢；按理应越来越快。

## 坑 / 错误做法

- 提审猜邮箱、扫 API 试错（已有 `feedback_reviewer_usernames.md` 仍不用）
- 多主题挤同一长会话，上下文膨胀后每步都钝
- 解释/汇报写成长文；工具空转、长轮询占回合
- 复述将要做什么，等人催才推下一步

## 正确做法

1. 先结论后证据；已知路径/账号先读 feedback，一次到位
2. 一任务做完即新开对话（归因 / 漏斗 / 文档勿叠）
3. 补数：发起 → 短查状态 → 验 3 行结论；禁无意义探活
4. 有下一步直接干

## 验证

同类活下一会话步数明显少于本会话；无「猜审人」类返工。
