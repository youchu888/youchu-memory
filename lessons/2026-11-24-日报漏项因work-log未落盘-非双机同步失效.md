# 日报漏项因 work-log 未落盘，不是双机同步失效

## 背景

new-mac 当晚做了设备终身价值首跑核验、部门汇总次留排查等，但 old-mac 权威定稿只推了「页面访问」一条。

## 坑 / 错误做法

- 以为 hosts 缺内容 = memory sync 坏了。
- 实活只停在 IDE 对话 / 本地 reports，**不写** `CHcode/.cursor/work-log/当日.md`。
- flush 用 ops-mirror 空壳顶上 → 同步「成功」但权威机仍汇不全。

## 正确做法

1. 多步数据活收尾立刻追加本机 `.cursor/work-log/YYYY-MM-DD.md`
2. 21:20 冲刺前自检有业务短句
3. 依赖：`daily-worklog-required.mdc` + flush 空壳 WARN + 导出勿用空壳覆盖满稿 + auto_draft 可升级定稿

## 验证

- flush 日志出现 `work-log quality biz=N;thin=0`
- `work-log/hosts/<本机>/当日.md` 含业务 bullet，无「仅 ops-mirror 兜底」独占
- 权威机合并稿能看到各机实活

## 关联

- 规则：`.cursor/rules/daily-worklog-required.mdc`
- 脚本：`pre_daily_report_flush.sh` · `worklog_dual_mac_sync.py` · `auto_draft_daily_report.py`
