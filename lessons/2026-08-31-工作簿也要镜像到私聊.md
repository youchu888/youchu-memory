# 工作簿也要镜像到私聊（原文 + 发群进展）

## 背景

主人 2026-08-31：工作簿也要镜像到私聊。此前群「今日工作簿」只发机器人群 + bus，因正文是 `【又初】` + `@worker_ant_bot`、没有显式 `@又初`，被 `should_mirror_group_to_private` 挡掉。

## 坑 / 错误做法

- 只按「显式 @又初」分流私聊镜像，工作簿被当成旁听
- Telethon 命中工作簿后 `return`，不走 `_notify_assignees`
- 发群进展不写 `tg_status` reply，主人私聊看不到

## 正确做法

1. 工作簿 roll call **视为派给又初**，走私聊镜像（不要求 @）
2. 原文入站（header=`今日工作簿`，正文最多 3500 字）；同一天 `inbound_dm` 只推一次
3. 发群成功后 `emit_reply(..., mirror_private=True)` 再推一份进展
4. `mirror_private=True` 的事件不再用正文 @ 规则二次过滤
