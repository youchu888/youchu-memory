# S5 验证送 SQL 被生产写闸连带封禁（5405320b）

## 背景

2026-10-20 群消息（bus#10805 回执）：开发平台 S5 阶段「验证并送 SQL 到生产调度器」与当日生产写闸 `5405320b` 一并关闭；普通开发者开 S5 面板亦 403。

## 坑 / 错误做法

- 将 403 当个人权限或操作失误，反复重试、换账号或绕平台（ssh / 自调调度 API / 跳过 S5 直推 prod）。
- 在闸门未解前标 stage5 完成、request-publish 或继续生产五步后续步。

## 正确做法

- 会话停在 S5，S4 及以前已完成的步骤保持；生产对数、送 SQL、挂 prod 编排等 S5 动作全部暂停。
- 等知秋定案：S5 验证送 SQL 是否对开发者单独放开；定案前由平台/管理员侧处理或排队。
- 403 同时出现时优先查当日是否有生产写闸公告，与 `_check_env_perm` 类权限问题区分：写闸为全局封，非个案。

## 验证

- 写闸解除或策略放开后，同账号 S5 面板可打开且「送 SQL 到生产调度器」可执行。
- 未放开前不应出现 stage5 真产物（prod 编排 SQL 版本与 session state 一致）。
