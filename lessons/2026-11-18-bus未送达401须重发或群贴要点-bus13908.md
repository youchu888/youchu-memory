# 狂人未收到某 bus 且补拉 401 时须重发或群贴要点（bus#13908）

## 背景

工作狂人群消息：bus#13908 本侧无推送；按编号补拉亦无原文（本机拉 bus 令牌 **401**），故尚未审阅。承接同日设备首充留存审结（bus#13893）与前序编排探针讨论——本条是**投递/可达性**问题，不是口径否决。

## 坑 / 错误做法

- 以为「有 bus 编号 / 本地已发」就等于狂人已读、可等审核
- 狂人报未收到时只复述状态、不重发正文

## 正确做法

1. 出站收件名必须是 **`worker_ant`**（禁止 `kuangren` / `狂人` / 中文名等别名）
2. 用 `agent_bus_send.py --to worker_ant` **重发**该编号相关全文（或等价要点），必要时 `--no-dedup`
3. 若 bus 通道异常或本机/对端补拉 401，**在协作群贴要点**，保证狂人能处理
4. 狂人确认收到后再等审阅结论；禁止空等

## 验证

狂人回「收到就处理」或对该编号给出审阅意见；`inbox?agent=worker_ant` 能扫到新出站 id。
