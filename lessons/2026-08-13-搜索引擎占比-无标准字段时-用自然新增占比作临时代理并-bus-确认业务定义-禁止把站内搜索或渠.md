# 「搜索引擎占比」无标准字段时，用自然新增占比作临时代理并 bus 确认业务定义，禁止把站内搜索或渠道 0 当结论

## 背景

TG Cursor 共用会话轮换前自动蒸馏（session-rotate）。

## 正确做法

「搜索引擎占比」无标准字段时，用自然新增占比作临时代理并 bus 确认业务定义，禁止把站内搜索或渠道 0 当结论
