# 干完就提交并 push，不必等主人再说「提交」

## 背景

主人 2026-10-30：「以后能不能干完就提交」。此前 Cursor user_rule 写「only commit when requested」，与主人习惯冲突；以本条为准。

## 正确做法

1. 可执行任务验收完成后立刻 `git commit`（汉字说明）
2. 立刻 `git push`（红线「提交即 push」），除非当次禁止推送
3. 回复带短 sha + 已 push / 未 push 原因
4. 例外：主人说先别交 / 只改不交
