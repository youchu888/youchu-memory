# 加筛选条件必须能指出需求原句，不能把 spec 概括当依据

## 坑

V1.0.11 入围加了 `app_id`+`device_id` 连安装且 `attribution_flag=1`。提交 `e3c7a674` 和 `spec.md` 只写「按 PRD《V1.0.11归因分析二期迭代》」，第一条入围条件是自己概括的实现，没有摘需求原句。

## 正确做法

被问「根据哪一句加的」时，只能贴需求原文。贴不出就说没有。不得把 spec、对接说明或 commit message 里的实现概括说成需求依据。
