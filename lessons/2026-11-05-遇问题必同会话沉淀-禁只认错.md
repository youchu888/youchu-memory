# 遇问题必同会话沉淀 · 禁只认错（私聊#609）

## 背景

主人私聊#609：「遇到的问题都要沉淀成记忆，后续不能再犯了阿」。当日已踩：点击率全新业务误套影子闸（#12455）、绿点 dispatch 断链（#603）等；`feedback_self_evolve_on_criticism.md` 一度缺失仍被 skill 引用。

## 坑 / 错误做法

- 口头「记住了」不写 lesson / feedback
- 等日报或「闲时」再沉，会话一换就丢
- 只改代码不落记忆；同坑隔天再犯
- 主题重合仍新建重复条，或该 update 旧条却不查重

## 正确做法

1. 纠正/翻车/断链当会话：写或 **update** lesson + `_index.md` / `MEMORY.md` 一行
2. 反复/严重：补 `feedback_*.md`；≥2 次或主人点名 → `pinned/NN-*.md`
3. 交付末尾：**已沉淀经验** + 路径
4. 下次同类：先 `lookup-rules.sh` / `_index.md`，打开≠用了，真改做法才算遵守
