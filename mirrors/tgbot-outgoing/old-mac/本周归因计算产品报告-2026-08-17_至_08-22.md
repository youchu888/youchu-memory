## 二、口径说明（产品版）

| 名词 | 含义 |
|---|---|
| 入围 | iOS + 自然量注册 + 客户端打「需归因」标记 |
| 候选 | 入围后，在 24h 内用同一公网 IP 命中过落地页点击/浏览，且进入结果表 |
| 有核透率 / 覆盖率 | 候选数 ÷ 入围数 |
| 归因成功率 | 成功数 ÷ 候选数（进了结果表之后的成功率） |
| 影子期 | 只出归因结果，不改用户档案渠道 |

> 没有候选 ≠ 归因失败；多数是「找不到可对齐的落地页」或「落地页渠道仍是 organic」。

## 五、候选覆盖率偏低 · 原因拆解（抽样）

对 **JHG-001**、业务日 **2026-08-20**、入围但未进结果表的样本抽 **500** 条，核对「注册 IP 前 24h 是否有同 IP 落地页」：

| 类型 | 条数 | 占比 | 产品含义 |
|---|---:|---:|---|
| 同 IP 完全无落地页 | 266 | 53.2% | 用户注册前未访问推广 H5，或 IP 因 NAT/换网对不上 |
| 有落地页但渠道全是 organic | 226 | 45.2% | H5 未带真实推广渠道码 |
| 有非 organic 落地页仍未进候选 | 8 | 1.6% | 时序/应用维度等更细条件未满足（需个案） |

**结论**：覆盖率低的主因仍是两类——**同 IP 无落地页**、**落地页渠道为自然量**；与上周周报一致。

## 七、给产品的行动建议

1. **未打需归因标记的产品**：先推客户端上报 `attribution_flag=1`，否则开通开关也不会出数。
2. **有入围、候选≈0 或覆盖极低**：优先查 H5 是否上报真实 channel，以及注册与落地页是否同公网 IP。
3. **DX-118 / JHA-128**：候选已有但成功率很低 → 优先补齐落地页/注册侧设备字段，提高打分。
4. **JHG-001**：关注候选内成功率波动（08-17 的 81% → 08-21 的 52% → 08-22 回升至 70%），建议运营侧盯设备字段完整度与投放落地页质量。
5. **回写**：除 SF-81 外均为影子期；开回写需业务单独拍板。
