一句话结论

透率低不是打分太严，而是大部分已打标注册进不了候选池。

进池要同时有：同产品同 IP 落地页 + 渠道非自然量 + 注册前 24 小时内。

本周主因只有两类：
A. 注册 IP 对不上落地页　B. 对上了 IP，但落地页渠道是自然量/空

分产品说人话

JHG-001（约 3.7%）——双因

  • 约一半：注册 IP 对不上任何落地页
  • 约四成：对上了，但落地页是自然量（落地页里自然量远多于推广）
  • 打标 IP 与推广落地页 IP 重合约 7.3%

SF-81 / SF-42（约 3.7% / 6.1%）——几乎全是对不上 IP

  • 落地页基本都是推广渠道（不是「记成自然量」）
  • 但注册 IP 与推广落地页 IP 重合仅约 4.6% / 6.5%
  • 落地页有量，IP 集合与注册侧错开（蜂窝切换 / 出口不一致等）

JHG-004（约 9%）

约八成无同 IP 落地页；重合约 12.5%，略好于 SF 系。
