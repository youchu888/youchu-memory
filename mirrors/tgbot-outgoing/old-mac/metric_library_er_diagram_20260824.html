2 · 表分区对照

区表说明
指标核 (v0.2) metric_concept / metric_label / metric_implementation / metric_impl_candidate concept 加 entity_code / main_event_code / related_event_codes；impl 加 dim_uses
元数据扩层 (v0.3 新) entity_dict / event_ext / role_dict 实体 · 事件扩字段 · 归属方式（注册时/当次事件…）
维度 dimension_standard 已有；v0.3 加 entity_code FK
流程闭环 (v0.3 新) report_metric_binding 报表↔concept；引用归零可 orphaned
已有元数据 glossaryterm / tabledefinition / columndefinition event_ext 不侵入 glossary；impl 挂物理表.列

3 · 关键关系（对照 spec）

  • G7-a：published 必填 concept.entity_code + main_event_code
  • G7-b：event_ext[main_event].entity_code == concept.entity_code（derived 可跨实体）
  • dim_uses：impl 上 JSON [{dim, role_code}]；role 写死在 impl，不是查询参数
  • 晋升：扫表只写 metric_impl_candidate，禁直建 concept
  • 派生：concept 自关联分子/分母；禁比率进 atomic
  • 报表闭环：report_metric_binding 引用计数；0 引用 + proposed 超 30 天 → orphaned
Phase 0 建表清单（spec §14）：新建 entity_dict / role_dict / event_ext / report_metric_binding； 改 metric_concept(+3) / metric_implementation(+dim_uses) / dimension_standard(+entity_code)。 拍板前仍禁 test metadata 抢跑建表。
