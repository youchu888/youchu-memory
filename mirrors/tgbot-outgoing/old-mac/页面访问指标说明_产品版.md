# 页面访问指标说明（产品版）

> **文档用途**：给产品 / 前端 / 报表同学核对口径、选字段、避免误算。  
> **数据表**：`dws.dws_app_page_visit_d_d`  
> **统计粒度**：天 × 产品（app_id）× 页面（page_key）  
> **统计主体**：仅**登录账号（uid）**；空 uid 的浏览不计入。  
> **版本**：2026-08-21（进入 / 跳转口径已按最新规则改定）  
> **数据侧联系人**：又初

---

## 1. 这张表能看什么

| 想看什么 | 用哪个字段 / 怎么算 |
|----------|---------------------|
| 页面被访问了多少次 | `pv_cnt` |
| 有多少个账号来过 | `BITMAP_COUNT(uid_cnt)` |
| 从站内别的页跳进来多少次 | `entry_cnt`（**进入**） |
| 从本页跳到别的明确页多少次 | `jump_cnt`（**跳转**） |
| 用户在本页停了多久 | `valid_stay_sec_sum` ÷ `valid_stay_page_cnt`（平均停留，秒） |
| 页面加载慢不慢 | `load_time_sum` ÷ `load_cnt`（平均加载，毫秒） |
| **跳出率** | `dropout_page_cnt` ÷ `stay_page_cnt`（见第 4 节） |

**注意**：表里只存次数、时长等**分子分母**，比率（跳出率、人均访问等）在查询或报表里现算，表里没有 `bounce_rate` 这类列。

## 2. 三个最容易混的概念

### 2.1 访问次数 `pv_cnt`

- **含义**：用户打开/浏览**本页**的次数。
- **挂账**：按**本页** `page_key` 统计。
- **包含**：站内跳入、外部/unknown 来路、自刷新（来路=本页）等，只要算一次有效浏览就 +1。

### 2.2 进入次数 `entry_cnt`（2026-08-21 定稿）

- **含义**：用户到达**本页**，且**来路是站内明确页面**的次数。
- **挂账**：按**本页** `page_key` 统计。
- **计入条件**（同时满足）：
  - 当前行是本页的浏览；
  - `referrer_page_key` 非空，且不等于 `unknown`（大小写不敏感）。
- **不计入**：
  - 来路为空 → 一般是外部直达、冷启动等；
  - 来路为 `unknown` → 埋点无法识别来路。

**和旧版的区别（重要）**  
旧版把「来路空或 unknown」算作进入（外部直接进入）；**新版反过来**——只有「来路明确」才算进入。产品看数时请按新版理解。

**示例**  
路径 `首页 → 列表页 → 详情页`：

- 列表页：`entry_cnt` +1（来路是首页）；
- 详情页：`entry_cnt` +1（来路是列表页）；
- 用户直接打开详情页（来路空）：详情页 **只有** `pv_cnt` +1，`entry_cnt` 不加。

### 2.3 跳转次数 `jump_cnt`

- **含义**：用户**从本页离开**，且**去向是另一个明确页面**的次数。
- **挂账**：按**来路页**（离开前的那个 `page_key`）统计，不是按目标页。
- **计入条件**（同时满足）：
  - `referrer_page_key` = 本页；
  - 目标 `page_key` 非空且不是 `unknown`；
  - 目标页 ≠ 来路页（**自刷新不算跳转**）。

**示例**（接上）  
从列表页点到详情页：列表页的 `jump_cnt` +1，详情页的 `pv_cnt` +1。

## 3. 常见疑问（今天核对过的结论）

### Q1：为什么很多页面 `pv_cnt` 远大于 `jump_cnt`？是不是算错了？

**不是 bug，是正常现象。**

- `pv_cnt` 看「来了本页几次」；
- `jump_cnt` 看「从本页明确跳去别的页几次」。

下面几类访问只会增加 `pv_cnt`，不会增加 `jump_cnt`：

| 情况 | 影响 |
|------|------|
| 来路为空或 `unknown` | 只算访问，不算进入（新版） |
| 用户在本页停留后退出 App / 去无效页 | 只算访问，不算跳转 |
| 自刷新（来路=本页） | 新版：**算进入、不算跳转**（见第 6 节待确认） |
| 视频页、末页等消费页 | 常见「有 PV、几乎无跳转」 |

prod 实测（2026-08-20）：有 PV 的行里约 **97%** 满足 `pv_cnt > jump_cnt`，属于预期分布。

### Q2：`entry_cnt` 和 `jump_cnt` 应该相等吗？

**不应该强行相等。**

同一条边「A → B」：B 的 `entry_cnt` +1，A 的 `jump_cnt` +1。  
但一个用户可以在 B 只看不走，或在 A 只看不跳，所以全站或单页上 **进入 ≈ 有明确来路的 PV**，通常 **大于跳转**。

### Q3：产品口头说的「跳出」和表里的字段怎么对应？

| 产品说法（口语） | 数据侧字段 | 说明 |
|------------------|------------|------|
| 从本页跳到别的页 | `jump_cnt` | 按来路页挂账 |
| 跳出率（页面留存） | `dropout_page_cnt` ÷ `stay_page_cnt` | 停留模型：末页或间隔 >30 分钟 |
| ~~(pv − jump) / pv~~ | **不要用** | 已废弃，会算出负值 |

**「跳出率」不要用 `(pv_cnt - jump_cnt) / pv_cnt`。**  
因为 `pv` 和 `jump` 挂账维度不同，相减可能为负（例如 08-20 当天约有 5,303 行出现负值）。

### Q4：跳出率会有负数吗？

**按定稿公式不会。**

- 公式：`dropout_page_cnt / stay_page_cnt`
- 取值区间：**0～1**（或 0%～100%）
- prod 已补数窗口 2026-07-21～08-20 实查：**无负值、无 dropout > stay**

若报表里出现负跳出率，请检查是否误用了 `(pv - jump) / pv`。

### Q5：想看「从哪来 / 到哪去」的路径分布怎么办？

- **看某页的进入次数、跳转次数**：用本表 `dws_app_page_visit_d_d` 即可。
- **看具体「来源页 → 目标页」的边、Top 路径**：要回查明细表  
  `dwd.dwd_app_page_view_d`，按 `referrer_page_key + page_key` 聚合。  
  本表是页面级汇总，**不存路径明细**。

## 4. 查询侧比率（报表 / 前端现算）

| 指标 | 公式 | 说明 |
|------|------|------|
| **跳出率** | `dropout_page_cnt ÷ stay_page_cnt` | 分母为 0 时展示 NULL 或「—」，勿强行填 0（除非产品另有约定） |
| 平均停留时长（秒） | `valid_stay_sec_sum ÷ valid_stay_page_cnt` | 末页 / 超时页不进分母 |
| 平均加载时长（毫秒） | `load_time_sum ÷ load_cnt` | 未加载完成不进分母 |
| 人均访问次数 | `pv_cnt ÷ BITMAP_COUNT(uid_cnt)` | 多页汇总时 uid 要先 `BITMAP_UNION` |

**上卷规则**：次数、时长类字段可 SUM；账号数用 `BITMAP_UNION` 后再 `BITMAP_COUNT`。**不要跨 app_id 直接 SUM uid_cnt。**

## 6. 待产品确认（1 项）

### 自刷新是否计入「进入」

**现状（按字面实现）**  
当 `referrer_page_key = 本页 page_key`（用户在当前页刷新）时：

- ✅ 计入 `pv_cnt`
- ✅ 计入 `entry_cnt`（因为来路非空且非 unknown）
- ❌ 不计入 `jump_cnt`（目标=来路，被排除）

**影响**  
部分 app 自刷新占比很高（如 TJ-027 进入里约一半为自刷新），会出现 **进入 ≈ PV、且远大于跳转**。  

**请产品确认**：自刷新是否应从「进入」中排除？确认后数据侧可改 ETL 并重跑 test / prod。

## 7. 一页纸对照（给开发 / 报表配字段）

```
用户行为                    pv_cnt    entry_cnt    jump_cnt
─────────────────────────────────────────────────────────
外部/unknown 打开本页         +1         —            —
站内 A→本页                   +1         +1           —（A 的 jump +1）
本页自刷新                    +1         +1*          —
本页→站内 B                   —          —            +1（挂在本页）
本页停留后退出                +1         —            —
```

\* 自刷新是否算进入 → **待产品确认（第 6 节）**
