> 整理人：又初 · 2026-07-27  
> 权威 DDL：`ops_system/04.dws/dws_session_duration_d/`、`ops_system/03.dwm/job_dwm_app_session_sid_d/`、`ops_system/04.dws/job_dws_user_page_stay_d/`

---

## 1. 先分清两条业务线

| 业务场景 | 主指标语义 | 后端应查表 | 粒度 |
|----------|------------|------------|------|
| **PRD 使用时长看板**（单次墙钟五档 + 日均五档柱状图） | `session_duration_sec` 墙钟秒；分档看 `duration_bucket` | `dws_session_duration_user_d` / `dws_session_duration_device_d` | 预聚合（切片维 + bucket） |
| **账户日停留汇总**（valid_stay 页间停留） | `valid_stay_sec_sum` 有效停留秒 | `dws_user_page_stay_d` | `uid × dt` 事实 |

**不要混口径**：页面 valid_stay ≠ session 墙钟；PRD 五档主指标不用 `valid_stay_sec_sum`。

---

## 2. 链路（知悉即可，API 一般不直连 DWM）

```
dwd.dwd_app_page_view_d
    ├─► dwd.dwd_app_page_stay_d          （页面停留明细，对账用）
    ├─► dwm.dwm_app_session_sid_d        （账号 sid 会话宽表）
    └─► dwm.dwm_app_session_sid_device_d （设备 sid 会话宽表）
            │
            ├─► dws.dws_session_duration_user_d    ← PRD 五档（账号）
            ├─► dws.dws_session_duration_device_d  ← PRD 五档（设备）
            └─► dws.dws_user_page_stay_d           ← uid 日停留汇总
```

- 分区列统一为 **`dt`（业务日，T-1 日批产出）**
- 有效会话过滤（进 DWS 前）：墙钟 `<5s` 或 `>12h` → `is_valid=0`，不进 daily 累加；单次分档含 bounce（bucket=0）

## 3. 后端主查表 · PRD 五档（合表 v2）

### 3.1 `dws.dws_session_duration_user_d`（账号侧）

**用途**：使用时长看板 — 按切片维 + 时长分档的启动次数 / 账号数 / 均值。

**主键**：`(dt, app_id, stat_grain, source_type, is_new, duration_bucket, device, user_type, country)`

| 字段 | 类型 | 说明 |
|------|------|------|
| dt | DATE | 分区日期 |
| app_id | VARCHAR(50) | 应用 |
| stat_grain | VARCHAR(16) | **`session`**=单次墙钟分档；**`daily`**=当日累加后再分档（查询必带） |
| source_type | VARCHAR(16) | `organic` / `channel` |
| is_new | TINYINT | 是否新用户（日快照口径） |
| duration_bucket | TINYINT | 时长分档 0~5（见 §5） |
| device | VARCHAR(50) | 设备类型 Android/iOS/PC 等 |
| user_type | VARCHAR(50) | 用户类型 NORMAL/VIP 等 |
| country | VARCHAR(200) | 国家 |
| session_cnt | BIGINT | **仅 stat_grain=session**：该分档启动次数 |
| user_cnt | BIGINT | 去重账号数（session/daily 均有） |
| duration_sum_sec | BIGINT | 墙钟时长合计秒 |
| avg_session_duration_sec | DECIMAL(20,2) | **仅 session**：单次平均墙钟秒 |
| avg_daily_duration_sec | DECIMAL(20,2) | **仅 daily**：日均墙钟秒 |
| bounce_cnt | BIGINT | **仅 session**：bounce 次数（单 PV 会话） |
| etl_time | DATETIME | ETL 写入时间 |

**stat_grain 填值规则**（同一行只填一侧均值列）：

| stat_grain | Y 轴含义 | 有值字段 | 无值字段 |
|------------|----------|----------|----------|
| `session` | 启动次数分布 | session_cnt, bounce_cnt, avg_session_duration_sec | avg_daily_duration_sec |
| `daily` | 账号数分布（当日累加后再分档） | user_cnt, avg_daily_duration_sec | session_cnt, bounce_cnt, avg_session_duration_sec |

**已废弃**：`dws_session_daily_user_d`（2026-07-25 合入本表，勿再查）

---

### 3.2 `dws.dws_session_duration_device_d`（设备侧）

与账号表同构，**无 `user_type` 列**；设备数字段为 `device_cnt`。

**主键**：`(dt, app_id, stat_grain, source_type, is_new, duration_bucket, device, country)`

其余字段、stat_grain 语义与账号表一致（`user_cnt` → `device_cnt`）。

**已废弃**：`dws_session_daily_device_d`

## 4. 后端可选表 · 账户日停留

### 4.1 `dws.dws_user_page_stay_d`

**用途**：账户粒度「页面有效停留」日汇总（非 PRD 五档柱状图）。

**主键**：`(dt, app_id, uid)` — 空 uid 已排除。

| 字段 | 类型 | 说明 |
|------|------|------|
| dt | DATE | 业务日 |
| app_id | VARCHAR | 应用 |
| uid | VARCHAR | 用户 ID（非空） |
| daily_valid_stay_sec | BIGINT | 当日 valid_stay 秒合计 |
| session_cnt | INT | 当日会话总数（含 is_valid=0） |
| valid_session_cnt | INT | 当日有效会话数（is_valid=1） |
| valid_stay_page_cnt | INT | 有效停留页数 |
| avg_valid_stay_sec_per_page | DECIMAL(12,2) | daily_valid_stay_sec / valid_stay_page_cnt |
| avg_valid_stay_sec_per_session | DECIMAL(12,2) | daily_valid_stay_sec / valid_session_cnt |
| channel | VARCHAR | sid 首会话渠道 |
| device | VARCHAR | sid 首会话设备 OS |
| user_type | VARCHAR | 优先日快照，缺失取 sid |
| is_new | TINYINT | 是否当日新用户（日快照） |
| source_type | VARCHAR | organic / channel（sid 首会话） |
| country | VARCHAR | 优先日快照 |
| etl_time | DATETIME | ETL 时间 |

**均值分母**：派生均值用 `valid_session_cnt`，不用全量 `session_cnt`（避免无效零停留会话稀释约 4 倍）。

---

## 5. `duration_bucket` 枚举（知秋候选 B · 全链统一）

单次（session）与日均（daily）**同一套秒级边界**；daily **无 bucket 0**。

| bucket | 名称 | 秒级区间（墙钟 / 日累加） |
|--------|------|-------------------------|
| 0 | bounce | 仅 session：单 PV 会话，不看时长 |
| 1 | ≤1 分钟 | (0, 60] |
| 2 | 1–5 分钟 | (60, 300] |
| 3 | 5–15 分钟 | (300, 900] |
| 4 | 15–30 分钟 | (900, 1800] |
| 5 | 30 分钟以上 | (1800, 43200]；daily 可 >43200 |

无效会话（<5s 或 >12h）：`is_valid=0`，`duration_bucket=NULL`，不进 daily 分档。

## 6. 典型查询（StarRocks）

### 6.1 单次使用时长五档（启动次数柱状图）

```sql
SELECT duration_bucket,
       SUM(session_cnt) AS launch_cnt,
       SUM(bounce_cnt)  AS bounce_cnt
FROM dws.dws_session_duration_user_d
WHERE dt = '2026-07-26'
  AND app_id = 'SF-81'
  AND stat_grain = 'session'
GROUP BY duration_bucket
ORDER BY duration_bucket;
```

### 6.2 日均使用时长五档（账号数柱状图）

```sql
SELECT duration_bucket,
       SUM(user_cnt) AS user_cnt,
       ROUND(SUM(duration_sum_sec) / NULLIF(SUM(user_cnt), 0), 2) AS avg_sec
FROM dws.dws_session_duration_user_d
WHERE dt = '2026-07-26'
  AND app_id = 'SF-81'
  AND stat_grain = 'daily'
GROUP BY duration_bucket
ORDER BY duration_bucket;
```

### 6.3 设备侧（同上，换表名，用 device_cnt）

```sql
SELECT duration_bucket, SUM(device_cnt) AS device_cnt
FROM dws.dws_session_duration_device_d
WHERE dt = '2026-07-26' AND app_id = 'SF-81' AND stat_grain = 'daily'
GROUP BY duration_bucket;
```

### 6.4 单用户日停留（valid_stay 线）

```sql
SELECT uid, daily_valid_stay_sec, valid_session_cnt,
       avg_valid_stay_sec_per_session
FROM dws.dws_user_page_stay_d
WHERE dt = '2026-07-26' AND app_id = 'SF-81' AND uid = 'xxx'
LIMIT 1;
```

## 9. 对接铁律（避免踩坑）

1. 查五档 DWS **必须带 `stat_grain`**，否则 session / daily 两种 Y 轴混算。
2. PRD「单次使用时长」「日均使用时长」对应 `avg_session_duration_sec` / `avg_daily_duration_sec`，**不是** `valid_stay` 字段。
3. 切片维空值在表里落 `''` 或 `organic`/`0` 兜底，前端筛「全部」时注意 OR 条件。
4. `session_cnt`（page_stay 表）含无效会话；算停留均值用 `valid_session_cnt`。
5. 已废弃表：`dws_session_daily_user_d`、`dws_session_daily_device_d` — 勿对接。
