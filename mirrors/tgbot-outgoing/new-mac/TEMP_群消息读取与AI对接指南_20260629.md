## 1. 三条通道（先分清）

| 通道 | 谁读群 | 用途 |
|------|--------|------|
| **A. 又初 TG Bot** | Bot API（`bot.py`） | 群里 **@又初** 提问 → AI 查数 / 写 SQL |
| **B. Telethon 旁听** | 真人号会话（`worker_ant_dispatch_watcher`） | **旁听** 群里 @worker_ant_bot 派单 → 私聊推给又初 |
| **C. agent-bus** | HTTP 轮询（`agent_bus_watcher`） | **工作狂人 ↔ 又初 AI** 正式互发（Bot 不能互 @） |

```
协作群 ──@又初──► Bot(A) ──Cursor AI──► 查数/SQL/回复
协作群 ──@worker_ant_bot──► Telethon(B) ──私聊──► 又初
工作狂人 ──agent-bus──► 又初 AI（C）──bus回传──► 工作狂人
```

## 2. 开通「群消息读取」（又初 Bot · 通道 A）

### 2.1 前置

1. 把 **又初 Bot** 拉进目标群（管理员建议开「读消息」权限）
2. 在 `omdb/tgbot/.env` 配置：

```bash
ALLOWED_GROUP_CHAT_IDS=-5376962870    # 群 chat_id（多个逗号分隔）
GROUP_ALLOWED_USERS=8740305767,...    # 允许 @又初 的 uid 白名单
GROUP_LISTEN_WITHOUT_MENTION=false    # 默认必须 @又初 才响应
```

3. 重启：`omdb/tgbot/restart.sh`

### 2.2 群里怎么用

- **必须** @又初 或 **回复** 又初 的消息（除非开了 `GROUP_LISTEN_WITHOUT_MENTION=true`）
- 授权用户发自然语言 → Bot 走 AI → 可跑 prod StarRocks（只读）
- 任务带来源标签：`群聊#N`（写入 `data/task_provenance.jsonl`）

### 2.3 给新用户开权限

- 管理员私聊又初 Bot：`/grant <uid> operator`
- 或把 uid 加进 `.env` 的 `GROUP_ALLOWED_USERS` 后 restart

## 3. 旁听群消息（Telethon · 通道 B）

> 不是让 AI 读全群聊天，而是 **旁听 @worker_ant_bot 的派单**。

### 3.1 一次性配置

```bash
# .env
TELEGRAM_API_ID=...          # my.telegram.org 申请
TELEGRAM_API_HASH=...
USER_SESSION_PATH=data/user_telegram
MONITOR_GROUP_CHAT_ID=-5376962870
WORKER_ANT_DISPATCH_ENABLED=true
TASK_DISPATCH_NOTIFY_USER_IDS=8740305767   # 派单推送给谁（又初 uid）
```

```bash
cd omdb/tgbot
python login_user_session.py   # 真人号登录一次
./start.sh                     # 已集成进主 Bot，无需单独 start_monitor
```

### 3.2 行为

- Telethon 真人号在群内，监听 **@worker_ant_bot** 发的消息
- 命中后 → **私聊** 通知 `TASK_DISPATCH_NOTIFY_USER_IDS`
- 原文存档：`incoming/worker_ant_group_inbox.jsonl`

## 4. AI 对接（Cursor Composer）

### 4.1 后端

```bash
# .env
AI_BACKEND=cursor
CURSOR_API_KEY=...
CURSOR_MODEL_WORK=composer-2.5      # 派单/核查用
CURSOR_MODEL_FAST=composer-2.5-fast # 总结/学习用
```

- 入口：`ai_client.py` → `claude_client.py`（Cursor Agent CLI / API）
- 全局串行锁：`agent_queue.py`（私聊/群聊/派单共用，防并发打架）

### 4.2 TG ↔ Cursor IDE 共享上下文

- 桥接文件：`.cursor/tgbot-bridge/context.jsonl`
- 每次 TG 问答自动 append；Cursor 侧 prompt 会读最近 8 条
- **常驻会话**：agent-bus poller `--wake` 唤醒 **同一 Cursor 对话**，不每条 spawn 新 Agent  
  → skill：`.cursor/skills/agent-bus-persistent-session/SKILL.md`

### 4.3 数据查询链路

```
用户提问 → AI 生成 [SQL: ...] → query_runner(prod my.cnf) → AI 总结 → 回群/私聊
```

铁律：默认 **prod** `52.221.240.167:9030`，别连 test 报结论。

## 5. 群机器人 / Agent 对接（通道 C · agent-bus）

### 5.1 服务

- Base：`http://54.255.236.159:8012/api/v1/agent-bus`
- Token：`dcp_`（`.claude/database/dc-platform.json`）
- 又初 agent 名：`youchu_ai` · 工作狂人：`worker_ant`

### 5.2 接口

| 动作 | 方法 |
|------|------|
| 发消息 | `POST /send` `{from_agent,to_agent,text}` |
| 收消息 | `GET /inbox?agent=youchu_ai&after_id=N` |
| 探活 | `GET /peek?agent=...&after_id=N` |

### 5.3 又初侧脚本

```bash
# 轮询（15s，可选唤醒 Cursor 主会话）
python .claude/database/scripts/notify/agent_bus_poll.py --wake --interval 15

# 回狂人
python .claude/database/scripts/notify/agent_bus_send.py --to worker_ant --text "..."
```

位点/去重：`.cursor/agent-bus/youchu_ai.offset` + `_processed.json` + `_sent.json`

### 5.4 TG 直连（不经 AI，秒发）

私聊又初 Bot：


## 7. 启停与排错

| 命令 | 作用 |
|------|------|
| `omdb/tgbot/start.sh` | 启主 Bot（含 agent-bus 轮询 + Telethon 派单） |
| `omdb/tgbot/stop.sh` | 停 Bot |
| `omdb/tgbot/status.sh` | 看进程/心跳 |
| `tail -f /tmp/tgbot-dc.log` | 看日志 |

常见问题：
- 群里 @了没反应 → 查 uid 是否在白名单、是否 @ 了机器人、群 id 是否在 `ALLOWED_GROUP_CHAT_IDS`
- agent-bus 重复消息 → 查 offset 是否写盘（`.cursor/agent-bus/*.offset`）
- 查数结果离谱 → 先确认连的是 **prod** 不是 test
