# 大漏斗（事件漏斗）· 后端对接说明

> 用途：与后端对齐 **查哪张表、字段含义、怎么上卷、转化率怎么算**。  
> 「大漏斗」与「事件漏斗」是同一需求；表名 `dws_app_event_funnel_d_d`。  
> session：`dev-20260807-big-funnel-001` · 口径：`metric_big_funnel_event_dictionary` · 更新：2026-08-11 · 又初

---

## 1. 一句话

按 **天 × 产品 × 新老（is_new）** 产出 **18 个业务事件** 的 **用户数 / 会话数 / 事件数**（宽表 54 指标列，空填 `0`）。  
**漏斗转化率不落库**，由查询侧用各事件 `*_user_cnt` 现算。

---

## 2. 主表

| 项 | 说明 |
|----|------|
| **表名** | `dws.dws_app_event_funnel_d_d` |
| **粒度** | `(dt, app_id, is_new)` 一天一产品一新老档一行 |
| **主键** | `(dt, app_id, is_new)` |
| **分区** | 按 `dt` 日分区，**查询必须带 dt** |
| **口径** | **仅账号 uid**；无 uid 记 `is_new=-1`，不进新/老；**不用 device_id** |
| **产出** | **Spark → Paimon**（主路径）；SR DDL 备日后同步，**当前勿默认当海豚 SR 日批表对接** |
| **业务日** | T-1 |
| **上游** | `dw.dw_user_event_detail_new`、`dwd.dwd_video_event_h`、`dwd.dwd_novel_event_d`、`dwd.dwd_comic_event_d` |

### 本轮非目标（勿对接）

- 中间长表 `dws.dws_app_event_funnel_metric_stg_d`（ETL 内部用，勿对外）
- 设备口径、`user_type` 维度名（统一用 `is_new`）
- 落库转化率 / 漏斗步率字段
- 小说/漫画新命名 `NOVEL_VIEW` / `COMIC_VIEW`（字典当前只取旧名 `VIEW`）

---

## 3. 维度字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `dt` | DATE / STRING | 业务日（分区键）；与源表分区一致 |
| `app_id` | VARCHAR / STRING | 产品 ID，与埋点一致 |
| `is_new` | TINYINT / INT | `1`=当日注册新用户 · `0`=老用户 · `-1`=无 uid 判不了 |
| `update_time` | DATETIME | ETL 写入时刻；业务一般不展示 |

### `is_new` 对接约定

| 取值 | 含义 | 接口建议 |
|------|------|----------|
| `1` | 新：当日有 `user_register` 的 uid，当天事件都算新 | 筛「仅新」 |
| `0` | 老：有 uid 且当日未注册 | 筛「仅老」 |
| `-1` | 无 uid（安装/SDK 等登录前场景常见） | **单独档**；勿并进 `0` |
| 不传 / 全部 | 新+老+无 uid | 见下节上卷 |

当前 Spark 实现：用当日 `user_register` 事件 uid 推导新老（与「注册日=当日」对齐）；未直连维表全量 JOIN。

---

## 4. 指标字段（18 × 3）

命名：`<前缀>_user_cnt` / `<前缀>_session_cnt` / `<前缀>_event_cnt`，类型均为整数，无数据为 **`0`（不是 null）**。

| 业务名 | 前缀 | 筛选摘要（与字典一致） |
|--------|------|------------------------|
| 安装 | `app_install` | `event = 'app_install'` |
| 注册 | `user_register` | `event = 'user_register'` |
| 登录 | `user_login` | `event = 'user_login'` |
| 订单创建 | `order_created` | `event = 'order_created'` |
| 订单支付 | `order_paid` | `event = 'order_paid'` |
| 金币消耗 | `coin_consume` | `event = 'coin_consume'` |
| SDK 初始化 | `sdk_init` | `event = 'sdk_init'` |
| 页面展示（多页） | `app_page_view` | 当日同 uid 下 `page_key` 去重 **>1**（按天，不按 sid） |
| 页面点击 | `page_click` | `event = 'page_click'` |
| 视频展示 | `video_view` | `video_behavior_key = 'video_view'`（小写） |
| 视频有效观看 | `video_play` | 有效观看四条件（见下） |
| 视频购买 | `video_purchase` | `event = 'video_purchase'` |
| 小说展示 | `novel_view` | `novel_behavior_key = 'VIEW'`（**大写**） |
| 小说阅读 | `novel_read` | 翻页/完成 + READ 新旧变体 IN 列表 |
| 小说购买 | `novel_purchase` | `event = 'novel_purchase'` |
| 漫画展示 | `comic_view` | `comic_behavior_key = 'VIEW'`（**大写**） |
| 漫画阅读 | `comic_read` | 翻页/完成 + READ 新旧变体 IN 列表 |
| 漫画购买 | `comic_purchase` | `event = 'comic_purchase'` |

### 三指标含义

| 后缀 | 含义 | 计算 |
|------|------|------|
| `_user_cnt` | 用户数 | `COUNT(DISTINCT uid)`；无 uid 不计入该指标 |
| `_session_cnt` | 会话数 | `COUNT(DISTINCT sid)`；空 sid 不计入 |
| `_event_cnt` | 事件数 | `COUNT(*)` 符合筛选的行数 |

### 视频有效观看四条件（任一成立）

1. `play_duration >= 5`
2. `video_duration * play_progress >= 5`
3. `video_behavior_key = 'video_complete'`
4. `play_progress >= 0.01`

---

## 5. 查询侧比率（接口现算）

漏斗步率 / 转化率 **不落库**。建议用 **用户数** 做转化（与看板常见口径一致）：

| 指标示例 | 建议字段名 | 公式 | 空值约定 |
|----------|------------|------|----------|
| 注册→登录转化 | `registerToLoginRate` | `user_login_user_cnt / user_register_user_cnt` | 分母 0 → `null` |
| 登录→下单转化 | `loginToOrderRate` | `order_created_user_cnt / user_login_user_cnt` | 分母 0 → `null` |
| 下单→支付转化 | `orderToPaidRate` | `order_paid_user_cnt / order_created_user_cnt` | 分母 0 → `null` |
| 展示→有效观看 | `viewToPlayRate` | `video_play_user_cnt / video_view_user_cnt` | 分母 0 → `null` |

具体漏斗步骤以产品配置为准；数仓只保证分子分母列已按口径产出。

### 上卷规则

| 场景 | 做法 |
|------|------|
| 同一 `dt`、同一 `app_id`，合并全部 `is_new` | 对各 `*_user_cnt` / `*_session_cnt` / `*_event_cnt` 做 **`SUM`**（同一 uid 只会落在一个 is_new 档） |
| 只要新+老、排除无 uid | `WHERE is_new IN (0, 1)` 后再 `SUM`，或分别取 `0`/`1` 行相加 |
| 多日合计 · 事件数 / 会话数 | 可 `SUM(*_event_cnt)` / `SUM(*_session_cnt)`（会话跨天可能重复，按产品是否接受） |
| 多日合计 · **用户数** | **禁止**直接 `SUM(*_user_cnt)`（会重复计人）；需明细或其它 UV 能力，本表不支持跨天精确 UV |
| 跨 `app_id` | **默认禁止**把多 app 的 `user_cnt` 相加当「全站 UV」 |

**禁止**：对行级转化率再 `AVG`；应 **先上卷分子分母，再除**。

---

## 6. 口径要点（前后端必须一致）

1. **账号口径**：用户数只认 `uid`；安装/SDK 等无 uid 行只进 `is_new=-1` 的会话/事件，不进用户数。
2. **大小写**：视频 `video_view` 小写；小说/漫画展示 `VIEW` **全大写**。写错会静默变成全 0。
3. **页面展示**：不是所有 `app_page_view`，而是当日 uid 维度 `page_key` 去重 >1 才计入。
4. **小说/漫画展示**：当前只取旧名 `VIEW`，未并入 `NOVEL_VIEW` / `COMIC_VIEW`（漫画侧漏损更大，属已知口径）。
5. **低覆盖事件**：部分 app 上购买类指标为 0 属正常，不删行。
6. **查询引擎**：以集群侧实际可读的 `dws.dws_app_event_funnel_d_d` 为准（Paimon 主）；SR 同步上线前不要写死「只连 StarRocks」。

## 7. 示例 SQL

### 7.1 单日 × 单 app × 分新老（列表）

```sql
SELECT
  dt,
  app_id,
  is_new,
  user_register_user_cnt,
  user_login_user_cnt,
  order_created_user_cnt,
  order_paid_user_cnt,
  video_view_user_cnt,
  video_play_user_cnt,
  CASE WHEN user_register_user_cnt > 0
       THEN user_login_user_cnt * 1.0 / user_register_user_cnt END AS register_to_login_rate,
  CASE WHEN video_view_user_cnt > 0
       THEN video_play_user_cnt * 1.0 / video_view_user_cnt END AS view_to_play_rate
FROM dws.dws_app_event_funnel_d_d
WHERE dt = '${biz_date}'
  AND app_id = '${app_id}'
ORDER BY is_new;
```

### 7.2 单日 × 单 app 合计（合并 is_new）

```sql
SELECT
  dt,
  app_id,
  SUM(user_register_user_cnt) AS user_register_user_cnt,
  SUM(user_login_user_cnt) AS user_login_user_cnt,
  SUM(order_created_user_cnt) AS order_created_user_cnt,
  SUM(order_paid_user_cnt) AS order_paid_user_cnt,
  SUM(app_page_view_user_cnt) AS app_page_view_user_cnt,
  SUM(video_view_user_cnt) AS video_view_user_cnt,
  SUM(video_play_user_cnt) AS video_play_user_cnt,
  CASE WHEN SUM(user_register_user_cnt) > 0
       THEN SUM(user_login_user_cnt) * 1.0 / SUM(user_register_user_cnt) END AS register_to_login_rate
FROM dws.dws_app_event_funnel_d_d
WHERE dt = '${biz_date}'
  AND app_id = '${app_id}'
  AND is_new IN (0, 1)   -- 可选：排除无 uid
GROUP BY dt, app_id;
```

## 8. 接口返回建议（可选）

列表行建议按「维度 + 需要的事件前缀」裁剪返回，不必一次吐 54 列。

| JSON 字段（示例） | 来源 | 备注 |
|-------------------|------|------|
| `dt` / `appId` / `isNew` | 维度列 | 驼峰按团队约定 |
| `userRegisterUserCnt` 等 | 对应 `*_user_cnt` | 已是整数，可直接返回 |
| `registerToLoginRate` 等 | 现算 | 分母 0 → `null` |

若前端画漏斗：接口返回有序步骤数组更清晰，例如  
`[{ step: "register", userCnt }, { step: "login", userCnt }, …]`，转化率在服务端或前端用相邻步相除即可。
