# 候选覆盖率偏低 · 原因拆解

> **窗口**：2026-08-03～08-07（与本周产品报告一致）  
> **环境**：生产只读  
> **口径**：iOS 自然量且客户端已打标（`attribution_flag=1`）→ 能否进入结果表（有 ≥1 条合格落地页候选）  
> **出具人**：又初 · 2026-08-08

---

## 一、先说结论

「候选覆盖率 / 透率」低，**不是算分阈值太严**，而是大部分打标注册**根本进不了候选池**。

要进候选，必须同时满足：

1. 同产品、同 IP 上有落地页浏览/点击  
2. 落地页渠道**不是**自然量（`organic` / 空）  
3. 落地页时间在注册前，且间隔 ≤ 24 小时  
4. 落地页日期落在注册日及前一日

本周拆漏斗后，主因只有两类（时序不满足占比很小；注册 IP 为空为 0）：

| 主因 | 含义（业务说法） |
|------|------------------|
| **A. 同 IP 无落地页** | 注册 IP 在前后窗口内对不上任何落地页访问 |
| **B. 同 IP 但落地页是自然量** | 对上了 IP，但落地页渠道记成自然量/空，规则直接排除 |

## 三、按产品说人话

### 1）JHG-001（透率约 3.7%）——双因叠加

- 约一半打标注册：**注册 IP 对不上任何落地页**  
- 约四成：对上了 IP，但落地页渠道是自然量（本周落地页里自然量约 520 万次、推广渠道约 150 万次）  
- 打标注册 IP 与「推广渠道落地页 IP」重合率仅约 **7.3%**  
- 时序不满足很少，不是主因  

**产品侧含义**：大量用户注册前没有「带推广渠道的落地页」轨迹；即使有同 IP 访问，渠道也常被记成自然量。

### 2）SF-81 / SF-42（透率约 3.7% / 6.1%）——几乎全是「对不上 IP」

- 落地页**几乎全是推广渠道**（本周自然量落地页为 0），问题不在「渠道被记成自然量」  
- 但打标注册 IP 与推广落地页 IP 重合率分别约 **4.6% / 6.5%**  
- SF-81 落地页量很大，去重推广 IP 却很少（约两千级），注册侧对不上  

**产品侧含义**：落地页有量，但**访问落地页的 IP 集合**和**打标自然量注册的 IP 集合**基本错开（常见于蜂窝网切换、代理、落地页与 App 出口 IP 不一致等）。不是「没做落地页」。

### 3）JHG-004（透率约 9%）——仍以「对不上 IP」为主

- 约八成无同 IP 落地页；少量同 IP 自然量；IP 重合率约 **12.5%**（略好于 SF 系）

### 4）DX-092 / YC-169 / DX-118 —— 周报透率被「开通前日期」低估

仅看配置生效后的 **08-06～08-07**：

| 产品 | 打标 | 有合格候选 | 候选占比 | 同 IP 仅自然量 | 同 IP 无落地页 |
|------|------|------------|----------|----------------|----------------|
| DX-092 | 511 | 183 | **35.8%** | 98 | 208 |
| YC-169 | 561 | 83 | **14.8%** | 130 | 341 |
| DX-118 | 197 | 16 | **8.1%** | 87 | 89 |

- DX-092：开通后候选占比已不低；周报 12.88% 仍含开通前空窗  
- YC-169：开通后约 15%，主因仍是无同 IP + 部分自然量落地页  
- DX-118：开通后仍低（约 8%），且本周**成功率**另有「分数低于阈值」问题（与透率是两件事）

### 5）TJ-002（透率 0）——没有落地页数据

- 自 2026-07-01 起，该产品在落地页点击/浏览明细中 **0 条**  
- 无落地页 → 必然无候选（与打标多少无关）

---

## 四、不是主因的项（本周已核对）

| 项 | 结论 |
|----|------|
| 注册 IP 为空 | 上述产品打标样本中均为 0 |
| 时序不满足（>24h 或时间颠倒） | 各产品占比约 0～2%，可忽略 |
| 打分阈值过严 | 只影响「有候选后是否成功」，不解释「没候选」 |

---

## 五、给产品的跟进建议（按优先级）

1. **TJ-002**：先确认落地页埋点 / 产品挂接是否接到数仓；当前链路侧无任何落地页事件。  
2. **SF-81 / SF-42**：重点查「落地页访问 IP」与「App 注册 IP」为何长期错开（网络出口、H5 与 App 上报差异），而不是先调归因阈值。  
3. **JHG-001**：并行两件事——提高推广渠道落地页覆盖；排查为何大量落地页渠道落成自然量。  
4. **新挂产品**：看透率请用**开通日及之后**，不要用整周含空窗的分母。  
5. **DX-118**：透率低与成功率低要分开盯；成功率需另看分数分布（本周未归因几乎全是低于阈值）。
