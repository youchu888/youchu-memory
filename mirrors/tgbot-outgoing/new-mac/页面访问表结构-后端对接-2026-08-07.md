## 查哪张表

| 项 | 说明 |
|----|------|
| 表 | `dws.dws_app_page_visit_d_d` |
| 粒度 | `dt` × `app_id` × `page_key` |
| 口径 | **仅账号**（无设备）；空 uid 已过滤 |
| 比率 | **不落库**，接口/SQL 现算 |
| 查询 | **必须带 `dt`** |

---

## 字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `dt` | DATE | 业务日 |
| `app_id` | VARCHAR(50) | 产品 |
| `page_key` | VARCHAR(64) | 页面标识 |
| `page_name` | VARCHAR(512) | 页面名（可空） |
| `pv_cnt` | BIGINT | 访问次数 PV |
| `uid_cnt` | BITMAP | 账号集合 → UV 用 `BITMAP_COUNT` |
| `entry_cnt` | BIGINT | 进入（来路空/`unknown`） |
| `jump_cnt` | BIGINT | 离开本页跳转（刷新不算） |
| `valid_stay_sec_sum` | BIGINT | 有效停留秒合计 |
| `valid_stay_page_cnt` | BIGINT | 有效停留页次 |
| `stay_page_cnt` | BIGINT | 停留明细总页次 |
| `dropout_page_cnt` | BIGINT | 跳出页次 |
| `load_time_sum` | BIGINT | 加载时长合计 |
| `load_cnt` | BIGINT | 有效加载次数 |
| `etl_time` | DATETIME | ETL 时间（可不展示） |

---

## 比率（现算）

| 指标 | 公式 |
|------|------|
| UV | `BITMAP_COUNT(uid_cnt)` |
| 跳出率 | `dropout_page_cnt / stay_page_cnt` |
| 平均停留秒 | `valid_stay_sec_sum / valid_stay_page_cnt` |
| 平均加载 | `load_time_sum / load_cnt` |
| 人均访问 | `pv_cnt / BITMAP_COUNT(uid_cnt)` |

分母为 0 → 返回 `null`。  
上卷：次数 `SUM`；UV 用 `BITMAP_UNION_COUNT`；**禁止** `SUM(BITMAP_COUNT(uid_cnt))`；比率先加总分子分母再除。

---

## 列表示例

```sql
SELECT
  page_key, page_name, pv_cnt,
  BITMAP_COUNT(uid_cnt) AS uv_cnt,
  entry_cnt, jump_cnt,
  CASE WHEN stay_page_cnt > 0
       THEN dropout_page_cnt * 1.0 / stay_page_cnt END AS bounce_rate,
  CASE WHEN valid_stay_page_cnt > 0
       THEN valid_stay_sec_sum * 1.0 / valid_stay_page_cnt END AS avg_stay_sec,
  CASE WHEN load_cnt > 0
       THEN load_time_sum * 1.0 / load_cnt END AS avg_load_time
FROM dws.dws_app_page_visit_d_d
WHERE dt = '${biz_date}' AND app_id = '${app_id}'
ORDER BY pv_cnt DESC;
```

## 口径提醒

- 进入 = 来路空或 `unknown`
- 跳转 = referrer=本页且目标≠本页
- 停留/跳出沿用 `dwd_app_page_stay_d`
- 本轮不做设备口径、不做 from→to 跳转边表
