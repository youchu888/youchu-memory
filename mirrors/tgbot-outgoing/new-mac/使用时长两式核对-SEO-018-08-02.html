4. 不一致原因（通俗）

打个比方：平均分把「缺考记 0 分」的人也算进人数 → 平均被拉低； 但数「参考人数」时又不算缺考的 → 用这个平均 × 参考人数，还原不出总分。
  • 平均 7 秒 = 121,279 ÷ 17,476（含 12,605 次 bounce）≈ 6.94 → 显示 7 秒
  • 分段次数 4,871：柱状图 不含 bounce
  • ① 用「含 bounce 的平均」×「不含 bounce 的次数」→ 34,097（偏小）
  • ② 日均人数与人均时长基本同一批人 → 120,819 ≈ 真值
错：7 × 4,871 = 34,097
对：6.94 × 17,476 = 121,279
或：24.90 × 4,871 = 121,279（只用有效会话）

5. 和 PRD「<5秒 / >12小时」的关系

PRD 5.5.4 要求过滤：单 session <5 秒、或 >12 小时。
情况是否已排除说明
<5s 且非 bounce已排除不进五档、不进总时长
>12 小时已排除同上
bounce（时长 0，也属 <5s）未完全排除单独留 bucket0；均时分母仍计入

当日无效非 bounce 约 12,234 条已滤掉。拉低均时的是 bounce 12,605，不是「两种 PRD 过滤都没做」。

7. 给协作方的结论

  1. 两式理论上都应 = 同一总时长；库内已平（121,279s）。
  2. 截图① 对不齐，是 均时含 bounce、次数不含 bounce。
  3. 不是 PRD 两种无效时长都没滤；<5s/>12h 非 bounce 已滤；bounce 被单独保留进了均时分母。
  4. 优化建议：均时与分段对 bounce 处理一致——要么均时也不含 bounce（则均时≈24.9s），要么分段展示含 bounce / 注明分母口径。
