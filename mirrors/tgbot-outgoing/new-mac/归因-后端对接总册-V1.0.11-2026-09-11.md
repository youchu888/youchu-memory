## 0. 三句话结论

1. **列表 / 详情主表不变**：仍读 `dws.dws_register_attribution_result_d`（必带 `dt`）。
2. **`is_run` 只控展示，不算门槛**：主列表继续 `IFNULL(is_run,0)=1`；**Mapper 过滤条件不用改**。
3. **新产品自动开展示**：日批对「当日入围且配置表无行」**只 INSERT**（`is_run=1` + `is_active=0` 走 default）；**不 UPDATE**，拉黑不会被刷回。

## 2. 入围口径（相对旧版）

| | 旧版 | V1.0.11 |
|--|------|---------|
| 注册 | `attribution_flag=1` + iOS + 自然/空渠道 + uid | **同左** |
| 安装 | 不强制 | **同 app + device** 的安装 `attribution_flag=1`，时间窗 **[注册−7天, 注册+1小时]** |
| `is_run` | **白名单开算** | **计算不读**；只控展示 |

影响：缺安装 flag 或装机不在窗内 → **不出结果行**（不是失败行）。入围真相源是结果表 / 双 flag，不是 `is_run`。

打分 / 回写：**不变**——`is_active=1` 用专属分，否则回落 `app_id='default'`；回写仍靠 `is_rewrite_channel=1`。

## 3. `is_run` / `is_active` 定稿（配置表）

| 项 | 约定 |
|----|------|
| 主列表 / 未传 `appId` | 只查 `IFNULL(is_run,0)=1` |
| `is_run=0` | 拉黑，不进主列表（传了具体 `appId` 仍可点开排查） |
| 日批 sync | 当日双 flag 入围且配置表**无行** → **INSERT** |
| 自动写入 | `is_run=1`，`is_active=0`（走 **default**），`is_rewrite_channel=0`，打分列抄 default 占位 |
| 改默认规则 | 后台改 `app_id='default'` |
| 特殊规则 | 对该 app 设 `is_active=1` 并改分 |
| 拉黑后 | sync **不 UPDATE** 已有行 → 不会被刷回 |
| 结果表 ETL | **不读** `is_run` |

**后端动作**：Mapper **保持**现网 `IFNULL(is_run,0)=1`；配置页文案勿写「`is_run`=唯一开算」。自动开的产品 `is_active=0` 表示走 default。

## 4. 结果表：实际得分评估（新列）

| 列 | 含义 |
|----|------|
| `score_brand` / `score_model` / `score_system` / `score_system_version` | 设备指纹四项**当时实际加分** |
| `score_time` | 时间衰减项实际加分 |
| `time_bucket_max_seconds` | 命中时间档（如 600 / 3600 / 21600 / 86400） |

成功行校验：`score =` 五分项之和。详情用 `AVG` / 按档 `COUNT`，不要反查当前 dim。

## 5. 无候选原因（新 ADS）

表：`ads.ads_register_attribution_no_candidate_reason_d_d`

| reason_code | reason_name |
|-------------|-------------|
| `reg_ip_empty` | 注册IP为空 |
| `no_landing_same_ip` | 无同app同IP落地页 |
| `landing_channel_organic_or_empty` | 同IP落地页渠道均为空或organic |
| `time_not_met` | 非自然落地页不满足注册前24小时窗 |
| `uncategorized` | 未归类 |

每条无候选入围注册只归一类。对账：`SUM(register_cnt) ≈ board.eligible − board.has_candidate`（同日同 app）。
