# is_run / 自动开归因 · 定稿说明（2026-09-11）

> 又初 · 与现网 `DwsAttributionAnalysisMapper`（`IFNULL(is_run,0)=1`）对齐

## 约定

| 项 | 定稿 |
|----|------|
| 主列表 / 未传 appId | 只查 `IFNULL(is_run,0)=1` |
| `is_run=0` | 未启用，不进主列表（传了具体 appId 仍可点开排查） |
| 自动开归因 | 日批 `dim_app_attribution_config_is_run_sync_d`：当日双 flag 入围且配置表**无行** → INSERT |
| 自动写入字段 | `is_run=1`，`is_active=0`（走 **default**），`is_rewrite_channel=0`，打分列抄 default 作占位 |
| 改默认规则 | 后台改 `app_id=default` |
| 特殊规则 | 后台对该 app `is_active=1` 并改分 |
| 拉黑 | `is_run=0`；sync **不 UPDATE** 已有行 |
| 结果表计算 | **不读** `is_run` |

## 后端

- Mapper **不用改**过滤条件。
- 配置文案勿写「is_run=唯一开算」。

## 数仓

- test：`dim_app_attribution_config_is_run_sync_d` 已发（INSERT-only + `is_active=0`）
- prod：若尚无该 task，随归因升级一并挂上
