## 2. 归因入围口径（ETL 绑定）

来源：`ops_system/04.dws/dws.dws_register_attribution_result_d/dws_register_attribution_result_d.sql`

注册进入 `reg_base` 须**同时满足**：

1. `dim.dim_app_attribution_config.is_run = 1`（白名单）
2. `dwd.dwd_user_register_d_v2.attribution_flag = 1`（**客户端打标**）
3. `device = ios`（小写 trim）
4. `channel` ∈ organic / natural / self / 空
5. `uid IS NOT NULL`

匹配成功 additionally 需要：注册 IP = 落地页 click/view IP，设备分 + 时间分 ≥ 阈值（默认 40）。
