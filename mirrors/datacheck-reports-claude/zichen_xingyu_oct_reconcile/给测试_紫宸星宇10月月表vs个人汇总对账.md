## 6. 月表为何说「没算错」（供测试排除月表嫌疑）

产上核对 SQL（SR）：

```sql
-- 部门 75，10-01～10-29，应等于同步月表充值 3,506,543.05
WITH ch AS (
  SELECT DISTINCT app_id, channel_code
  FROM dim.dim_channel_info_all
  WHERE dept_id = 75
)
SELECT ROUND(SUM(m.revenue_total) / 100, 2) AS rev_yuan,
       SUM(BITMAP_COUNT(m.channel_reg_ids)) AS daily_new_sum
FROM ads.ads_channel_metrics_daily_d m
INNER JOIN ch
  ON m.app_id = ch.app_id AND m.channel = ch.channel_code
WHERE m.dt BETWEEN '2026-10-01' AND '2026-10-29';
```

实测结果：`rev_yuan = 3506543.05`（与同步月表充值一致）；日新增相加 `2450304`（与月表新增 `2450222` 差 82，可忽略）。

> 注意：2026-10-31 06:38 月表已重算到含 **10-30**，当前表合计变为新增 2,531,990 / 充值 3,633,239.05。和测试对「截至 10-29 那版同步数」时，请仍用上面窗口，不要拿含 10-30 的当前月表去比旧个人 CSV。
